POST
/v4/leads/search

Search 52M+ Decision Makers

Query the DataCloud database with industry, geography, company size, revenue brackets, and CXO seniority filters. Returns paginated profile summaries with masked contacts at zero credit cost.

Request Body Parameters

Parameter Type Description
industryoptional string Filter by sector (e.g. saas, fintech, d2c, manufacturing).
cityoptional string City or region (e.g. bengaluru, mumbai, delhi_ncr).
seniorityoptional array Roles to target: ["founder", "cxo", "vp_sales", "cto"].
limitdefault: 25 integer Number of results to return (max 100 per page). 
curl -X POST "https://api.leadintelai.in/v4/leads/search"   -H "Authorization: Bearer lai_live_YOUR_KEY"   -H "Content-Type: application/json"   -d '{
    "industry": "saas",
    "city": "bengaluru",
    "seniority": ["founder", "cto"],
    "limit": 2
  }'
