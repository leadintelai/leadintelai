## ⚡ Quick Upload (3 Steps)

### Option A: Git Command Line (Fastest)

```powershell
# 1. Navigate to folder
cd "d:\New folder"

# 2. Initialize and commit
git init
git add .
git commit -m "Complete LeadintelAI website"

# 3. Create repo on github.com, then:
git remote add origin https://github.com/YOUR_USERNAME/leadintelai.git
git push -u origin main
```

### Option B: GitHub Desktop (Easiest)

1. Open GitHub Desktop
2. File → Add Local Repository → Select `d:\New folder`
3. Commit → Publish Repository

### Option C: Manual Upload

1. Go to https://github.com/new
2. Create repository named `leadintelai`
3. Drag all 16 files to GitHub
4. Click "Commit changes"
