# LeadintelAI - Premium 3D B2B Data & Marketing Platform

LeadintelAI is a visually stunning, high-performance web platform designed for B2B data selling, WhatsApp automation, and mass email marketing. Built with a focus on premium aesthetics, 3D interactivity, and smooth user experience.

## ✨ Features

- **Premium 3D Landing Page**: Interactive 3D background effects using Three.js and smooth scrolling animations with GSAP.
- **Dynamic AI Chatbot**: Intelligent chatbot with iOS-style spring animations and context-aware responses.
- **Advanced Auth Flow**: 
  - Sliding split-panel Login/Signup UI.
  - Interactive OTP verification simulation.
  - Liquid-style password strength indicator.
  - Secure simulation for specific demo credentials.
- **Project Hub**: Central dashboard for managing multiple product portals.
- **B2B Lead Generation Dashboard**:
  - Advanced search filters.
  - Locked/blurred contact data with "Unlock" simulation.
  - Wallet balance integration UI.
- **WhatsApp Automation Dashboard**:
  - Broadcast campaign management.
  - Analytics visualization.
  - Live inbox and Chatbot flow management UI.
- **Pricing & About Sections**: Clean, informative pages for service offerings and company vision.
